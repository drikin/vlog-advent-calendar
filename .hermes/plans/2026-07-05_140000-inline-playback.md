# インライン動画再生 & 連続再生 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** カレンダー内でYouTube動画をページ遷移なしでインライン再生でき、連続再生（プレイリスト）で自動的に次の動画に進む機能を追加する。

**Architecture:** YouTube IFrame Player API を使い、VideoCardクリック時にモーダル/オーバーレイでインライン再生。再生終了またはキーボード操作で次の動画に自動遷移する連続再生モード。既存の視聴済みマーク機能はそのまま活用し、インライン再生時にも視聴済みとしてマークする。

**Tech Stack:** Next.js 16 (React 19), Tailwind CSS 4, YouTube IFrame Player API (no external npm packages needed)

---

## 現状の理解

- **VideoCard** (`VlogCalendarClient.tsx:96-175`): `<a>` タグでYouTubeへの外部リンク。クリックで `onWatch(videoId)` を呼び出して視聴済みマーク。
- **YouTubeVideo**: `{ videoId, title, thumbnail, publishedAt, channelId, channelName, channelHandle }`
- **カレンダー動画**: `monthDates` 配列に `{ date, videos[] }` として格納。ストリーク順ソート済み。
- **視聴済み**: `WatchedMap` (Map<string, string>) で localStorage + API 二重管理。
- **依存関係**: 外部動画プレイヤーライブラリなし。最小構成を維持したい。

## 设计方針

1. **YouTube IFrame API の直接使用** — `react-youtube` 等のnpmパッケージは不要。Google提供の `iframe_api` をscriptタグでロードするだけで十分。依存ゼロ。
2. **モーダルオーバーレイ方式** — カレンダーから離れず再生。ESC / 背景クリックで閉じる。
3. **連続再生** — 同日内の動画は自動で次へ。日跨ぎモードで「次の日」の動画も自動再生可能。
4. **キーボードショートカット** — J/Kで前後、Spaceで一時停止、ESCで閉じる。
5. **視聴済み連動** — インライン再生時も既存の `handleWatch` をトリガー。

```tsx
"use client";

import { useEffect, useRef, useCallback } from "react";

interface YouTubePlayerProps {
  videoId: string;
  onEnd?: () => void;
  onPlay?: () => void;
  onPause?: () => void;
  autoplay?: boolean;
  className?: string;
}

// Singleton — load the IFrame API script once
let apiLoadPromise: Promise<void> | null = null;

function loadYouTubeAPI(): Promise<void> {
  if (apiLoadPromise) return apiLoadPromise;
  apiLoadPromise = new Promise((resolve) => {
    if ((window as any).YT?.Player) {
      resolve();
      return;
    }
    const tag = document.createElement("script");
    tag.src = "https://www.youtube.com/iframe_api";
    const firstScript = document.getElementsByTagName("script")[0];
    firstScript.parentNode?.insertBefore(tag, firstScript);
    (window as any).onYouTubeIframeAPIReady = () => resolve();
  });
  return apiLoadPromise;
}

export interface YouTubePlayerRef {
  play: () => void;
  pause: () => void;
  seekTo: (seconds: number) => void;
  getCurrentTime: () => number;
}

export default function YouTubePlayer({
  videoId,
  onEnd,
  onPlay,
  onPause,
  autoplay = true,
  className,
}: YouTubePlayerProps) {
  const containerRef = useRef<HTMLDivElement>(null);
  const playerRef = useRef<any>(null);
  const eventsRef = useRef({ onEnd, onPlay, onPause });
  eventsRef.current = { onEnd, onPlay, onPause };

  useEffect(() => {
    let destroyed = false;
    let player: any;

    loadYouTubeAPI().then(() => {
      if (destroyed || !containerRef.current) return;
      const YT = (window as any).YT;
      player = new YT.Player(containerRef.current, {
        videoId,
        width: "100%",
        height: "100%",
        playerVars: {
          autoplay: autoplay ? 1 : 0,
          modestbranding: 1,
          rel: 0,           // 関連動画を同じチャンネルのみに
          fs: 1,            // フルスクリーン許可
          playsinline: 1,   // iOSインライン再生
        },
        events: {
          onStateChange: (e: any) => {
            // YT.PlayerState.ENDED === 0, PLAYING === 1, PAUSED === 2
            if (e.data === 0) eventsRef.current.onEnd?.();
            if (e.data === 1) eventsRef.current.onPlay?.();
            if (e.data === 2) eventsRef.current.onPause?.();
          },
        },
      });
      playerRef.current = player;
    });

    return () => {
      destroyed = true;
      if (player?.destroy) player.destroy();
    };
  }, [videoId, autoplay]);

  return (
    <div ref={containerRef} className={className} />
  );
}
```

```tsx
"use client";

import { useEffect, useCallback } from "react";
import YouTubePlayer from "./YouTubePlayer";

interface VideoModalProps {
  videoId: string;
  title: string;
  channelName: string;
  onClose: () => void;
  onNext?: () => void;
  onPrev?: () => void;
  onEnded?: () => void;
  hasNext?: boolean;
  hasPrev?: boolean;
}

export default function VideoModal({
  videoId,
  title,
  channelName,
  onClose,
  onNext,
  onPrev,
  onEnded,
  hasNext,
  hasPrev,
}: VideoModalProps) {
  // ESC key to close
  const handleKeyDown = useCallback(
    (e: KeyboardEvent) => {
      if (e.key === "Escape") onClose();
      if (e.key === "ArrowRight" || e.key === "l") onNext?.();
      if (e.key === "ArrowLeft" || e.key === "k") onPrev?.();
      if (e.key === " ") {
        e.preventDefault();
        // Toggle play/pause — handled by player natively via focus
      }
    },
    [onClose, onNext, onPrev]
  );

  useEffect(() => {
    document.addEventListener("keydown", handleKeyDown);
    // Prevent body scroll when modal is open
    document.body.style.overflow = "hidden";
    return () => {
      document.removeEventListener("keydown", handleKeyDown);
      document.body.style.overflow = "";
    };
  }, [handleKeyDown]);

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/80 backdrop-blur-sm">
      {/* Backdrop — click to close */}
      <div className="absolute inset-0" onClick={onClose} />

      {/* Modal content */}
      <div className="relative z-10 w-full max-w-4xl mx-4">
        {/* Header bar */}
        <div className="flex items-center justify-between mb-2 px-1">
          <div className="min-w-0 flex-1 mr-4">
            <h3 className="text-white text-sm font-medium truncate">{title}</h3>
            <p className="text-gray-400 text-xs truncate">{channelName}</p>
          </div>
          <div className="flex items-center gap-2 shrink-0">
            {hasPrev && (
              <button
                onClick={(e) => { e.stopPropagation(); onPrev?.(); }}
                className="w-8 h-8 rounded-full bg-white/10 hover:bg-white/20 text-white flex items-center justify-center transition-colors"
                title="前の動画 (K)"
              >
                ‹
              </button>
            )}
            {hasNext && (
              <button
                onClick={(e) => { e.stopPropagation(); onNext?.(); }}
                className="w-8 h-8 rounded-full bg-white/10 hover:bg-white/20 text-white flex items-center justify-center transition-colors"
                title="次の動画 (J)"
              >
                ›
              </button>
            )}
            <button
              onClick={(e) => { e.stopPropagation(); onClose(); }}
              className="w-8 h-8 rounded-full bg-white/10 hover:bg-white/20 text-white flex items-center justify-center transition-colors"
              title="閉じる (ESC)"
            >
              ✕
            </button>
          </div>
        </div>

        {/* Player — 16:9 */}
        <div className="aspect-video bg-black rounded-lg overflow-hidden">
          <YouTubePlayer
            videoId={videoId}
            onEnd={onEnded}
            autoplay={true}
          />
        </div>

        {/* Keyboard hints */}
        <div className="flex justify-center gap-4 mt-2 text-[10px] text-gray-500">
          <span>ESC 閉じる</span>
          <span>J / → 次</span>
          <span>K / ← 前</span>
        </div>
      </div>
    </div>
  );
}
```

```tsx
// インライン再生
const [playingVideoId, setPlayingVideoId] = useState<string | null>(null);
const [isModalOpen, setIsModalOpen] = useState(false);

// 再生リスト: 全動画をフラットに（ストリーク順のまま）
const playList = useMemo(() => {
  return activeDays.flatMap(d => d.videos);
}, [activeDays]);

// 現在の再生インデックス
const playingIndex = playingVideoId
  ? playList.findIndex(v => v.videoId === playingVideoId)
  : -1;

const openPlayer = useCallback((videoId: string) => {
  setPlayingVideoId(videoId);
  setIsModalOpen(true);
  // 視聴済みマーク（既存機能）
  handleWatch(videoId);
}, [handleWatch]);

const closePlayer = useCallback(() => {
  setIsModalOpen(false);
  // 少し遅延させてからplayerをアンマウント
  setTimeout(() => setPlayingVideoId(null), 100);
}, []);

const playNext = useCallback(() => {
  if (playingIndex < playList.length - 1) {
    const next = playList[playingIndex + 1];
    setPlayingVideoId(next.videoId);
    handleWatch(next.videoId);
  }
}, [playingIndex, playList, handleWatch]);

const playPrev = useCallback(() => {
  if (playingIndex > 0) {
    const prev = playList[playingIndex - 1];
    setPlayingVideoId(prev.videoId);
    handleWatch(prev.videoId);
  }
}, [playingIndex, playList, handleWatch]);

const onVideoEnded = useCallback(() => {
  if (playingIndex < playList.length - 1) {
    playNext();
  } else {
    closePlayer();
  }
}, [playingIndex, playList.length, playNext, closePlayer]);
```

## リスク・注意点

1. **YouTube IFrame APIのロードタイミング** — 初回クリック時にAPIスクリプトをロードするため、少しラグが発生する可能性。対策: ページロード時にprefetchする (`loadYouTubeAPI()` をuseEffectで事前呼び出し)。
2. **モバイルでの全画面再生** — iOS Safariでは `playsinline: 1` を設定しても全画面になる場合がある。これはYouTubeの仕様であり回避困難。
3. **YouTubeクォータ** — IFrame API自体はAPIクォータを消費しない（埋め込み再生は無料）。
4. **既存の視聴済みリンクの後方互換** — `<a>` タグを `<button>` に変更するが、右クリック→新規タブで開きたいユーザー向けに、長押しまたは副次的なリンクを残すことを検討。
5. **パフォーマンス** — `playList` (flatMap) は月次で最大31日×9チャンネル=279本。React再レンダリングの負荷は無視できるレベル。
